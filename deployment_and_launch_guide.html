🌐 Step 1: Purchasing a Domain & Setting Up DNS

A custom domain (e.g. shahdolcabs.com, bandhavgarhvoyages.in, or touratsdl.com) establishes trust with passengers and hotel partners.

1. Where to Buy Your Domain

For Indian businesses, .in and .co.in are affordable (₹399–₹699/year), while .com offers global recognition.

  • Hostinger.in: Great pricing with UPI/Paytm payment support.
  • Namecheap.com: Includes free lifetime WHOIS privacy protection.
  • Cloudflare Registrar: Sells domains at wholesale cost with zero markups.

2. DNS Records to Configure

Once purchased, open the DNS Management dashboard of your registrar and add these two records: 

# Record 1: Apex Domain (@) pointing to Vercel
Type:  A
Name:  @
Value: 76.76.21.21

# Record 2: Subdomain (www) pointing to Vercel
Type:  CNAME
Name:  www
Value: cname.vercel-dns.com
🚀 Step 2: Push Code to GitHub & Deploy to Vercel ($0 Cost)

Follow these exact terminal commands and steps to make your site live to the world in under 3 minutes.

1

Create a New Repository on GitHub

1. Go to github.com/new in your browser.
2. Name the repository: cab-rider-platform.
3. Choose Private or Public, and leave "Initialize with README" unchecked (because your code already has files).
4. Click Create repository.

2

Push Your Code from This Computer

Open your terminal in this project folder and run:

PowerShell / Command Prompt 
# Link your local repo to GitHub (replace YOUR_GITHUB_USERNAME with your real username)
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/cab-rider-platform.git

# Rename main branch to match GitHub standard
git branch -M main

# Push all code, map data, and HTML files
git push -u origin main
3

Deploy on Vercel with 1-Click

1. Go to vercel.com and sign in with your GitHub account.
2. Click Add New... ➔ Project.
3. You will see cab-rider-platform in the list. Click Import.
4. In the Project Configuration, keep default settings (Framework: Next.js).
5. Click Deploy. Vercel will build and launch your site in ~60 seconds with a free URL like: https://cab-rider-platform.vercel.app.

4

Link Your Custom Domain in Vercel

In your Vercel Dashboard ➔ Project Settings ➔ Domains ➔ Type your domain (e.g. shahdolcab.in) and click Add. Vercel will automatically generate your free SSL certificate and make your domain live!

🗄️ Step 3: Setting Up Supabase Cloud PostgreSQL (Free)

Your app currently stores data locally in data/database.json. For high concurrency across multiple devices on the cloud, connect Supabase in 2 minutes.

  1. Create a free account at supabase.com.
  2. Click New Project and select India (Mumbai) as the region for the lowest network latency.
  3. Go to the SQL Editor tab on the left sidebar.
  4. Copy the contents of the file already in your project: supabase_schema.sql and click Run. This creates the users, rides, and driver_locations tables.
  5. Go to Project Settings ➔ API and copy your Project URL & service_role key.
  6. In Vercel ➔ Project Settings ➔ Environment Variables, add: 
    NEXT_PUBLIC_SUPABASE_URL = https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY = eyJh...your-secret-key
    The app will instantly switch to PostgreSQL with zero code changes!

🖥️ Option 2 Runbook: If You Choose a Dedicated VPS (Ubuntu)

If you prefer your own private Linux machine instead of Vercel, copy-paste these commands into your Ubuntu server terminal:

Ubuntu 22.04 / 24.04 Server Terminal 
# 1. Update OS packages & install Node.js 20 & Git
sudo apt update && sudo apt upgrade -y
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx git certbot python3-certbot-nginx

# 2. Clone your code to the server
cd /var/www
sudo git clone https://github.com/YOUR_GITHUB_USERNAME/cab-rider-platform.git
cd cab-rider-platform
npm install
npm run build

# 3. Run the application 24/7 in background using PM2
sudo npm install -g pm2
pm2 start npm --name "shahdol-cab" -- start
pm2 startup
pm2 save

# 4. Configure Nginx Reverse Proxy
sudo nano /etc/nginx/sites-available/shahdolcab
# (Paste proxy_pass http://localhost:3000; block)
sudo ln -s /etc/nginx/sites-available/shahdolcab /etc/nginx/sites-enabled/
sudo systemctl restart nginx

# 5. Get Free SSL Certificate for your domain
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
